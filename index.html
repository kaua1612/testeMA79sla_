Sistema de Cadastro de Motores em Python

Documentação técnica do protótipo monolítico em memória

Sobre o Projeto e Local de Desenvolvimento

Este projeto foi desenvolvido durante as atividades de programação no CentroWEG, unidade educacional do SENAI localizada dentro do parque fabril da WEG em Jaraguá do Sul – SC.

O objetivo do algoritmo é simular o gerenciamento básico de motores elétricos industriais (cadastro, listagem, busca e exclusão) diretamente em memória, aplicando lógica de programação estruturada sem a necessidade de um banco de dados externo.

Arquitetura e Funcionamento do Código

O script foi estruturado de forma monolítica (todo contido em um único arquivo .py) e dividido em responsabilidades claras utilizando funções e estruturas nativas do Python:

1. Armazenamento (Array + Dicionários)

A variável global motores = [] atua como um array dinâmico. Cada motor cadastrado é armazenado como um dicionário contendo id, modelo, fabricante, potencia_cv, tensao_v e rpm.

2. Controle de ID Sequencial

A variável proximo_id garante que cada motor receba um identificador único autoincremental, evitando conflitos mesmo após a exclusão de registros anteriores.

3. Tratamento de Exceções

Blocos try / except ValueError protegem a entrada de dados numéricos (Potência, Tensão, RPM e ID), impedindo que o sistema feche inesperadamente caso um texto seja digitado.

4. List Comprehension na Busca

A função buscar_motor() percorre o array comparando textos em minúsculo (.lower()), permitindo encontrar motores por trechos do modelo ou fabricante.

Mapeamento das Funções (CRUD em Memória)

Função Operação Descrição Técnica
cadastrar_motor() Create Coleta os dados técnicos via input(), valida os tipos numéricos e insere o dicionário na lista com .append().
listar_motores() Read Verifica se o array está vazio; caso contrário, itera sobre todos os dicionários exibindo as especificações formatadas.
buscar_motor() Search Filtra registros por correspondência parcial de texto no modelo ou fabricante sem diferenciar maiúsculas e minúsculas.
excluir_motor() Delete Localiza o índice do motor através do id informado usando enumerate() e o remove com .pop().
menu() Loop Principal Mantém a interface de terminal ativa via laço while True até que o usuário escolha a opção 0.

Trecho Central da Estrutura de Dados

Exemplo de como cada motor é estruturado dentro do array em Python:

motor = {
    "id": proximo_id,
    "modelo": "W22 IR3 Premium",
    "fabricante": "WEG",
    "potencia_cv": 10.0,
    "tensao_v": 380,
    "rpm": 1750,
}
motores.append(motor)
