01

Contexto Acadêmico e Local de Desenvolvimento

Este software foi idealizado e desenvolvido durante a formação técnica no CentroWEG, escola do SENAI integrada diretamente ao parque fabril da WEG no município de Jaraguá do Sul, Santa Catarina.

O desafio proposto consistiu em construir um sistema funcional de gerenciamento de motores industriais (inspirado nas linhas reais da empresa, como W22 IR3 Premium, W21 Magnet e W50), utilizando exclusivamente recursos nativos da linguagem Python em um único arquivo (arquitetura monolítica), sem dependência de bancos de dados externos (SQL/NoSQL) ou bibliotecas de terceiros.

02

Estrutura de Dados e Armazenamento em Memória

Para substituir um banco de dados relacional durante a fase de testes, o programa combina duas estruturas fundamentais do Python: Listas (Arrays Dinâmicos) e Dicionários (Chave-Valor).

Array Global (motores = [...])

Funciona como a "tabela" principal do sistema. Cada posição da lista armazena um registro completo de motor. O array já inicia populado com 3 motores WEG para agilizar testes imediatos de listagem, busca e edição.

Dicionário por Registro (dict)

Representa cada linha da tabela. Permite acesso rápido e semântico aos atributos técnicos do motor através de chaves nomeadas: id, modelo, fabricante, potencia_cv, tensao_v e rpm.

Chave Primária (proximo_id)

Simula o AUTO_INCREMENT de bancos de dados. Inicia em 4 (após os 3 itens iniciais) e apenas incrementa. Se o ID 2 for excluído, o próximo cadastro recebe ID 4, evitando duplicidade de identificadores.

Tipagem e Integridade

Os dados são convertidos para seus tipos corretos antes de serem salvos: strings limpas com .strip(), ponto flutuante (float) para potência em CV e inteiros (int) para tensão (Volts) e rotação (RPM).

Dicionário de Campos do Objeto Motor

Chave Tipo Python Exemplo Real Finalidade Técnica
"id" int 1 Identificador único imutável usado para localizar o motor nas operações de edição e exclusão.
"modelo" str "W22 IR3 Premium" Código ou linha comercial do motor elétrico.
"fabricante" str "WEG" Marca fabricante do equipamento.

03

Anatomia Detalhada das Funções (CRUD)

Cada funcionalidade foi isolada em uma função específica para manter o código legível e modular, mesmo estando dentro de um único arquivo.

CREATE

cadastrar_motor()

  • Escopo Global: Utiliza a instrução global proximo_id para modificar o contador externo dentro do escopo local da função.
  • Validação de Campos Vazios: Verifica if not modelo or not fabricante: impedindo registros incompletos.
  • Blindagem contra Erros (try/except): Caso o usuário digite letras nos campos de potência, tensão ou RPM, a exceção ValueError é capturada, exibe um alerta amigável e aborta o cadastro com return sem travar o sistema.
  • Persistência em Memória: Adiciona o dicionário ao final da lista com motores.append(motor) e incrementa proximo_id += 1.
READ

listar_motores()

  • Guarda de Lista Vazia: Checa if not motores: antes de tentar iterar, informando caso todos os registros tenham sido apagados.
  • Formatação via f-strings: Percorre cada dicionário m no array motores e imprime todos os parâmetros técnicos alinhados em uma única linha legível no terminal.
SEARCH

buscar_motor()

  • Normalização Case-Insensitive: Converte tanto o termo digitado pelo usuário quanto os valores armazenados para letras minúsculas usando .lower(). Assim, buscar por "weg" encontra "WEG".
  • List Comprehension: Filtra a lista em uma única expressão Python ([m for m in motores if termo in ...]), permitindo busca por substring (trechos parciais do nome ou modelo).
UPDATE

editar_motor()

  • UX no Terminal (Manter Valor Atual): Ao localizar o dicionário pelo id, o sistema exibe o valor atual entre colchetes, por exemplo: Novo modelo [W22 IR3 Premium]:.
  • Atualização Seletiva: Se o usuário apenas pressionar ENTER (string vazia), a condição if novo_modelo: é falsa e o dado original é preservado intacto. Apenas os campos preenchidos são sobrescritos por referência direta no dicionário.
DELETE

excluir_motor()

  • Rastreamento de Índice com enumerate(): Como a exclusão em listas Python exige a posição (índice) do elemento, o laço for i, m in enumerate(motores): obtém simultaneamente o índice i e o dicionário m.
  • Remoção Segura: Ao encontrar o id correspondente, motores.pop(i) remove o item da memória e retorna o objeto removido para exibir a confirmação com o nome do modelo apagado.
04

Fluxo de Execução e Ciclo de Vida

1

Ponto de Entrada (if __name__ == "__main__":)

Garante que o loop interativo menu() só seja iniciado quando o arquivo for executado diretamente no terminal, permitindo importar suas funções em outros scripts caso necessário.

2

Loop Infinito Controlado (while True)

A função menu() exibe continuamente as 6 opções disponíveis. Após concluir qualquer operação (cadastrar, listar, editar, etc.), o fluxo retorna automaticamente ao menu principal.

3

Encerramento Limpo (break)

Somente quando o usuário digita 0, o comando break interrompe o laço while True e encerra a execução do processo Python na memória RAM.

Código-Fonte Completo (cadastro_motores.py)

Copie o código abaixo, salve como cadastro_motores.py e execute no terminal com python cadastro_motores.py: 

# Lista (array) global pré-preenchida com 3 motores WEG de exemplo para testes
motores = [
    {
        "id": 1,
        "modelo": "W22 IR3 Premium",
        "fabricante": "WEG",
        "potencia_cv": 10.0,
        "tensao_v": 380,
        "rpm": 1750,
    },
    {
        "id": 2,
        "modelo": "W21 Magnet IR5 Ultra",
        "fabricante": "WEG",
        "potencia_cv": 25.0,
        "tensao_v": 440,
        "rpm": 3540,
    },
    {
        "id": 3,
        "modelo": "W50 Industrial",
        "fabricante": "WEG",
        "potencia_cv": 150.0,
        "tensao_v": 440,
        "rpm": 1185,
    },
]

proximo_id = 4


def cadastrar_motor():
    global proximo_id
    print("\n--- CADASTRAR NOVO MOTOR ---")
    modelo = input("Modelo/Código do motor: ").strip()
    fabricante = input("Fabricante (ex: WEG): ").strip()

    if not modelo or not fabricante:
        print("\n[ERRO] Modelo e fabricante são obrigatórios!")
        return

    try:
        potencia = float(input("Potência (em CV): "))
        tensao = int(input("Tensão nominal (em Volts, ex: 220, 380, 440): "))
        rpm = int(input("Rotação (RPM): "))
    except ValueError:
        print("\n[ERRO] Potência, tensão e RPM devem ser valores numéricos!")
        return

    motor = {
        "id": proximo_id,
        "modelo": modelo,
        "fabricante": fabricante,
        "potencia_cv": potencia,
        "tensao_v": tensao,
        "rpm": rpm,
    }

    motores.append(motor)
    proximo_id += 1
    print(f"\n[SUCESSO] Motor '{modelo}' cadastrado com ID {motor['id']}!")


def listar_motores():
    print("\n--- LISTA DE MOTORES CADASTRADOS ---")
    if not motores:
        print("Nenhum motor cadastrado no momento.")
        return

    for m in motores:
        print(
            f"ID: {m['id']} | Modelo: {m['modelo']} | Fabricante: {m['fabricante']} | "
            f"Potência: {m['potencia_cv']} CV | Tensão: {m['tensao_v']}V | {m['rpm']} RPM"
        )


def buscar_motor():
    print("\n--- BUSCAR MOTOR ---")
    termo = input("Digite o modelo ou fabricante para buscar: ").strip().lower()

    encontrados = [
        m
        for m in motores
        if termo in m["modelo"].lower() or termo in m["fabricante"].lower()
    ]

    if not encontrados:
        print("Nenhum motor encontrado com esse termo.")
        return

    print(f"\nForam encontrados {len(encontrados)} motor(es):")
    for m in encontrados:
        print(
            f"ID: {m['id']} | Modelo: {m['modelo']} | Fabricante: {m['fabricante']} | "
            f"Potência: {m['potencia_cv']} CV | Tensão: {m['tensao_v']}V | {m['rpm']} RPM"
        )


def editar_motor():
    listar_motores()
    if not motores:
        return

    try:
        id_editar = int(input("\nDigite o ID do motor que deseja editar: "))
    except ValueError:
        print("[ERRO] Digite um ID numérico válido.")
        return

    for m in motores:
        if m["id"] == id_editar:
            print(
                f"\nEditando ID {m['id']} ({m['modelo']}). Pressione ENTER para manter o valor atual:"
            )

            novo_modelo = input(f"Novo modelo [{m['modelo']}]: ").strip()
            novo_fabricante = input(f"Novo fabricante [{m['fabricante']}]: ").strip()
            nova_potencia = input(f"Nova potência CV [{m['potencia_cv']}]: ").strip()
            nova_tensao = input(f"Nova tensão V [{m['tensao_v']}]: ").strip()
            novo_rpm = input(f"Nova rotação RPM [{m['rpm']}]: ").strip()

            try:
                if novo_modelo:
                    m["modelo"] = novo_modelo
                if novo_fabricante:
                    m["fabricante"] = novo_fabricante
                if nova_potencia:
                    m["potencia_cv"] = float(nova_potencia)
                if nova_tensao:
                    m["tensao_v"] = int(nova_tensao)
                if novo_rpm:
                    m["rpm"] = int(novo_rpm)

                print(f"\n[SUCESSO] Motor ID {id_editar} atualizado com sucesso!")
            except ValueError:
                print(
                    "\n[ERRO] Valores numéricos inválidos. A edição foi cancelada."
                )
            return

    print(f"\n[AVISO] Nenhum motor encontrado com o ID {id_editar}.")


def excluir_motor():
    listar_motores()
    if not motores:
        return

    try:
        id_excluir = int(input("\nDigite o ID do motor que deseja excluir: "))
    except ValueError:
        print("[ERRO] Digite um ID numérico válido.")
        return

    for i, m in enumerate(motores):
        if m["id"] == id_excluir:
            removido = motores.pop(i)
            print(
                f"\n[SUCESSO] Motor '{removido['modelo']}' (ID {id_excluir}) removido!"
            )
            return

    print(f"\n[AVISO] Nenhum motor encontrado com o ID {id_excluir}.")


def menu():
    while True:
        print("\n" + "=" * 40)
        print("   SISTEMA DE CADASTRO DE MOTORES (WEG)")
        print("=" * 40)
        print("1. Cadastrar novo motor")
        print("2. Listar todos os motores")
        print("3. Buscar motor por modelo/fabricante")
        print("4. Editar motor existente (por ID)")
        print("5. Excluir motor (por ID)")
        print("0. Sair")

        opcao = input("\nEscolha uma opção: ").strip()

        if opcao == "1":
            cadastrar_motor()
        elif opcao == "2":
            listar_motores()
        elif opcao == "3":
            buscar_motor()
        elif opcao == "4":
            editar_motor()
        elif opcao == "5":
            excluir_motor()
        elif opcao == "0":
            print("\nEncerrando o sistema...")
            break
        else:
            print("\n[ERRO] Opção inválida! Tente novamente.")


if __name__ == "__main__":
    menu()
